# AdPreview — Umbraco 17 wireframe

## Document type property editor — preview state

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Ad Preview                                                     [↗]  │
│                                                                      │
│ ┌──────────────────────────────────────────────────────────────────┐ │
│ │ [image selected from Media]                                     │ │
│ │                                                                  │ │
│ │  ┌────────────────────────────────────────────────────────────┐  │ │
│ │  │ Title                                                     │  │ │
│ │  │ Description                                               │  │ │
│ │  └────────────────────────────────────────────────────────────┘  │ │
│ └──────────────────────────────────────────────────────────────────┘ │
│                                                                      │
│ [Edit ad]                                      [Remove]              │
└──────────────────────────────────────────────────────────────────────┘
```

- **Preview:** renders the selected image and, when `overlay` is true, title/description over it.
- **Edit ad:** opens an inline editor using UUI controls; image selection uses the Umbraco media picker.
- **Remove:** clears the value back to the stable JSON shape with empty fields.
- **Link behavior:** preview opens the configured URL in a new tab; editor remains in place.

## Edit state

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Edit ad                                                              │
│                                                                      │
│ Image   [thumbnail / Select media]                                  │
│ Title   [____________________________________________]               │
│ URL     [____________________________________________]               │
│ Description [_______________________________________]                │
│ Tooltip [__________________________________________]                 │
│ Referrer[__________________________________________]                 │
│ CSS     [__________________________________________]                 │
│         [ ] Overlay title and description on image                  │
│                                                                      │
│                                      [Cancel] [Save]                 │
└──────────────────────────────────────────────────────────────────────┘
```

- **Loading:** show UUI loader while media selection is being resolved.
- **Empty:** show a neutral image placeholder and “Select media”; no broken image URL.
- **Error:** show an inline alert if media selection fails; preserve entered fields.
- **Save:** emits `UmbChangeEvent` with JSON `{ img, title, description, url, tooltip, referrer, css, overlay }`.
- **Cancel:** discards edits and leaves the last saved value untouched.

## Compatibility

- Property editor alias remains `AdPreview`.
- Storage remains JSON and preserves the original v7/v8 field names and casing in the serialized value.
- This wireframe is the approval gate for the Umbraco 17 Lit implementation.
